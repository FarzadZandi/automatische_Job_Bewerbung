jobfilter

One run from job search to filled application forms. You only check and submit.

1Prepare

Prepare searches and scores ads, creates packages, selects each CV, builds its PDF, and updates the form data. Cover letters are written only when you press Apply next. It can run in the background.

Setup check

Checks documents, profile, Word, Claude and the extension export without using model tokens.

Answer bank

Recurring factual answers stay on this laptop and use zero model tokens. Fill a gap once; jobfilter reuses only the scope you approve.

Learned from submitted forms

Filled for your review when a new question is very similar; shown as a suggestion when it is only somewhat similar. Learned only when you record an application as submitted.

Add job links

Paste one URL per line, Title | URL, or a Markdown job-alert link. Job boards are never fetched. Links that cannot be matched safely wait for the advertisement text below.
