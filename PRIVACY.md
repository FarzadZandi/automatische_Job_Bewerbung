# Privacy

Candidate sources, generated documents, application records, and configuration stay local in `workspace/`, `Job App Docs/`, `Bewerbungen/`, and ignored root files. The setup chat reads only material the person connects. At application time Claude Haiku receives job text, relevant CV and letter excerpts, and answer-bank facts through the person's own Claude Code sign-in. Never publish private folders. Run `python tools/check_privacy.py <folder>` before sharing.
